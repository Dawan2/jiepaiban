## 3. 正式版核心规则速查（供实现槽位对齐）

1. 新建项目 → **自动 5 节拍**（钩子/冲突/升级/反转/悬念钩子），数量固定；
2. 编辑页**左侧 5 项导航** = 五个节拍，含状态点；
3. 画面**宫格仅 3 或 2**，每格只有白话画面描述，是分镜的替代物；
4. **衔接字段不进 AI**（连同备注、节拍名称一起硬排除，CI 断言）；
5. **Prompt 实时组装**（≤500ms，顺序固定，来源标注，所见即所发，提交即快照）;
6. **生成队列**：节拍=生成单元，持久化、并发默认 2、自动重试 3 次、错误五归类；
7. **成片页固定 5 段卡片**，逐段下载 + 顺序连播；一键拼接按钮 V1.0 置灰占位；
8. **禁止分镜入口**（全站 UI/路由/API，代码评审 checklist 项）；
9. 版本线：**V1.0 本迭代（5.1–5.5）→ V1.1 题材模板与一键拼接 → V1.2 协作**。
