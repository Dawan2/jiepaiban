## 2. 关键事实与决策记录

1. **原始 PRD PDF 缺失（已核实）**：接手时远端仅有 `main` 一个分支、一个初始提交（只含空 README），仓库与任务上下文中均无 PDF。已按任务要求给出合理 PRD 骨架，所有推导性内容在 PRD 中以 `[假设]` 显式标注。
2. **远端无既有成果**：已 `git fetch --prune` 核对远端全部分支，不存在其他 wave/slot 的产出，本次交付为从零建立，无重做/覆盖风险。
3. **领域模型决策**：采用 Project → Episode → Scene → Beat → Shot → Take 六层结构；Beat（节拍，叙事单元）与 Shot（镜头，生成单元）分层。若原 PRD 将二者合一，模型可无损退化为 Beat=Shot，backlog 中 T-D2 拆分粒度需相应合并。
4. **优先级切分原则**：P0 = 单人可跑通的最小工业闭环（剧本 → 节拍板 → 提示词+角色注入 → Seedance 生成 → 审核 → 素材包导出）；P1 = 批量提效与质量保障；P2 = 规模化。
5. **架构建议**（详见 PRD 第 7 节）：单体后端 + Redis 任务队列 + PostgreSQL + 对象存储 + Seedance Provider 适配层，非最终裁决，Wave 2 实现槽位可基于 T-E0 spike 结论调整。
