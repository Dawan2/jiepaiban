# 信息架构（Information Architecture）

- 文档编号：`PRD-003`
- 版本：`v1.0`
- 状态：**BASELINE**
- 归属：Wave 1 / Slot P2 / Cycle W1
- 上游：[`prd.md`](./prd.md)（`PRD-001`）、`METH-001 §10.2`
- 下游：[`ui-spec.md`](./ui-spec.md)

> **页面锁**：一级页面**恰为三个**——项目列表 / 核心编辑器 / 成片。
> 新增一级页面属方法论变更，产品内不得自行扩展（`METH-001 §10.2`、`METH-002 §11`）。

---

## 1. 全局布局（Global Layout）

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部栏 TopBar：项目上下文 · 总时长 · 保存态 · 全局动作          │
├────────────┬─────────────────────────────────────────────────┤
│            │                                                 │
│ 左侧导航    │              主编辑区 Main                       │
│ LeftNav    │              （随页面切换内容）                   │
│            │                                                 │
│ · 项目列表  │                                                 │
│ · 核心编辑器│                                                 │
│ · 成片      │                                                 │
└────────────┴─────────────────────────────────────────────────┘
```

三区职责：

| 区域 | 职责 | 不承担 |
| --- | --- | --- |
| 左侧导航 `LeftNav` | 三个一级页面入口 + 当前页高亮 | 不放业务动作、不放板级操作 |
| 顶部栏 `TopBar` | 当前项目上下文、总时长与区间提示、保存态、页面级全局动作 | 不放节拍帧编辑、不放 prompt |
| 主编辑区 `Main` | 页面主体内容（列表 / 五板编辑 / 成片） | 不承载导航语义 |

---

## 2. 页面清单与路由（Pages & Routes）

| # | 页面 | 代号 | 路由 | 主对象 | 主要模块 |
| --- | --- | --- | --- | --- | --- |
| 1 | 项目列表 | `PAGE-LIST` | `/projects` | `project` 集合 | M1（新建入口）、项目生命周期 |
| 2 | 核心编辑器 | `PAGE-EDITOR` | `/projects/:project_id/editor` | `project` + `beat_list[5]` | M2、M3、M4、M5 |
| 3 | 成片 | `PAGE-FINAL` | `/final`、`/final/:project_id` | 成片记录 | M6 |

**路由规则：**

1. `/` 重定向到 `/projects`。
2. 编辑器不提供"板级路由"（如 `/beat/3`）——板是页内单元，不是页面单元；可用锚点滚动定位，不改变页面数量。
3. 无效 `project_id` 返回可读错误页并提供返回项目列表入口。
4. 不存在第四个一级路由；任何新能力必须落在上述三个路由之内（含 V1.1/V1.2）。

## 3. 导航模型（Navigation Model）

```
LeftNav
├── 项目列表 /projects
│     └── [点击项目] ──► 核心编辑器 /projects/:id/editor
│     └── [新建项目] ──► 核心编辑器（新实例，5 板已就位）
│     └── [复用项目] ──► 核心编辑器（新实例，结构参数继承 / 内容清空）
├── 核心编辑器 /projects/:id/editor
│     └── [去成片] ──► 成片 /final/:id
└── 成片 /final
      └── [回到编辑器] ──► /projects/:id/editor
```

| 规则 | 说明 |
| --- | --- |
| `NAV-1` | 核心编辑器必须有项目上下文；无上下文时导航到编辑器则跳项目列表并提示先选项目 |
| `NAV-2` | 页面切换保留项目上下文（顶部栏显示当前项目） |
| `NAV-3` | 离开编辑器前若有未保存内容，先完成自动保存或提示失败 |
| `NAV-4` | 导航项恰为 3 个，顺序固定：项目列表 → 核心编辑器 → 成片 |

## 4. 页面 1：项目列表（`PAGE-LIST`）

### 4.1 区域构成

| 区域 | 内容 |
| --- | --- |
| 顶部栏 | 页面标题「项目列表」+ 主动作「新建项目」 |
| 主区 | 搜索框 + 项目卡片/行列表 |

### 4.2 列表项字段

| 字段 | 来源 | 说明 |
| --- | --- | --- |
| 项目名 | `project.name` | 点击进入编辑器 |
| 总时长 | `project.total_duration` | 70–90s 正常态；越界警示 |
| 生成完成度 | `beat_list` 中 `video_url` 非空数 / 5 | 形如 `3/5` |
| 更新时间 | 系统 | 默认倒序 |
| 行内动作 | — | 编辑 / 复用 / 去成片 |

### 4.3 状态

| 状态 | 呈现 |
| --- | --- |
| 空态 | 空态说明 + 「新建项目」主动作（`US-7-04`） |
| 加载中 | 骨架列表，满足 `NFR-1` ≤1s 首屏可交互 |
| 检索无结果 | 「无匹配项目」+ 清除关键词入口 |
| 加载失败 | 可读错误 + 重试 |

## 5. 页面 2：核心编辑器（`PAGE-EDITOR`）

**这是唯一的创作页面**，承载 M2 编辑器、M3 组装器、M4 生成、M5 衔接。

### 5.1 区域构成

```
TopBar：项目名（可改）· 总时长 88s（70–90s）· 已保存 · [生成整集] [去成片]
────────────────────────────────────────────────────────────────
Main（纵向 5 块节拍板，顺序 B1→B5，不可重排）

┌ B1 · 开篇钩子 · G1 · 0–8s · 8s ─────────────────── 可生成 ┐
│ 板级槽位：本段情绪 ｜ 镜头节奏 ｜ 剧情核心                    │
│ 宫格（左→右，3 格）：[冲击] [反应] [环境]                     │
│ Prompt 面板（只读）：固定前缀 + 情绪 + 时长 + 节奏 + 剧情核心   │
│ 板尾：本板结束 → 进入下一板：[音频预接]        [生成本板]      │
└──────────────────────────────────────────────────────────────┘
┌ B2 · 矛盾建立 · G2 · 8–25s · 17s ───────────────────────────┐ …
┌ B5 · 断集留客 · G5 · 70–88s · 18s（2 宫格） ────────────────┐
│ 板尾：无转场 / 黑屏截断（只读）                                │
└──────────────────────────────────────────────────────────────┘
```

### 5.2 节拍板内层级（Board Anatomy）

| 层级 | 元素 | 数据 | 可编辑 |
| --- | --- | --- | --- |
| L1 板头 | `Bn` · 节拍名 · `Gn` · 时间位 · 时长 · 状态 | `beat_name`、`group_id`、`time_range` | 仅时长（≤30s）；节拍名/组号只读 |
| L2 板级槽位 | 本段情绪 / 镜头节奏 / 剧情核心 | `emotion`、`ai_param.camera_rhythm`、`ai_param.plot_core` | 是 |
| L3 宫格区 | 3 格（B1–B4）/ 2 格（B5），左→右 | `frame_list[].content` | 是（内容），格数与帧序只读 |
| L4 Prompt 面板 | 只读组装结果 + 复制 | `prompt_final` | 否 |
| L5 板尾 | 组间衔接选择 + 生成动作 + 结果预览 | `transition_rule`、`video_url` | 衔接可选（B5 只读） |

**层级红线：** L3 之下**不存在更细层级**。宫格内不得出现时长、转场、排序、子画面等任何控件（`PRD-001 §1.3`）。

### 5.3 板状态机

| 状态 | 进入条件 | 可用动作 |
| --- | --- | --- |
| `待补全` | 必填缺失或时长 >30s | 编辑；生成不可用 |
| `可生成` | 必填齐备 + 时长合规 + prompt 无转场词 | 生成本板 |
| `排队中` | 已提交 | 取消（若支持）；编辑受限 |
| `生成中` | 任务执行 | 等待；编辑受限 |
| `已生成` | 成功写入 `video_url` | 预览、下载、重新生成 |
| `生成失败` | 任务失败 | 查看原因、重试 |

### 5.4 状态

| 状态 | 呈现 |
| --- | --- |
| 首次进入 | 5 板骨架 + 占位提示，全部为 `待补全` |
| 总时长越界 | 顶部栏警示（<70s 或 >90s），说明当前值与目标区间；不阻断编辑，阻断"可交付" |
| 单板超 30s | 板头即时报错，`待补全` |
| 保存失败 | 顶部栏失败态 + 重试 |

## 6. 页面 3：成片（`PAGE-FINAL`）

### 6.1 区域构成

| 区域 | 内容 |
| --- | --- |
| 顶部栏 | 页面标题「成片」+ 当前项目上下文 + 主动作「导出飞书」 |
| 主区（列表态） | 项目维度成片列表：项目名 / 总时长 / 完成度 n/5 / 更新时间 |
| 主区（详情态） | 分板视频列表（B1–B5）+ 衔接总表 + 成片登记区 |

### 6.2 详情态内容

| 分区 | 内容 | 来源 |
| --- | --- | --- |
| 分板视频 | B1–B5 各一行：节拍名、时长、视频预览、下载 | `beat.video_url` |
| 衔接总表 | 5 行：B1→B2、B2→B3、B3→B4、B4→B5、B5→下一集，含枚举名与「后期合成」阶段标注 | `beat.transition_rule` |
| 成片登记 | 成片链接、备注、登记时间 | 成片记录 |
| 交付校验 | 缺片提示（列出缺失板号）；齐备才可标记可交付 | 派生 |

### 6.3 状态

| 状态 | 呈现 |
| --- | --- |
| 空态 | 「暂无成片」+ 去编辑器入口 |
| 部分完成 | 完成度 `n/5` + 缺失板号 + 回编辑器入口 |
| 全部完成 | 可导出飞书、可登记成片、可标记可交付 |
| 导出失败 | 可读原因 + 重试 |

## 7. 实体与页面映射（Entity ↔ Page）

```
project (1) ──── beat_list[5] ──── beat (5)
                                    ├── frame_list[3 或 2] ── frame
                                    ├── ai_param
                                    ├── transition_rule（挂本板，指向下一板）
                                    ├── prompt_final
                                    └── video_url
```

| 实体 | 创建于 | 编辑于 | 消费于 |
| --- | --- | --- | --- |
| `project` | `PAGE-LIST`（新建/复用） | `PAGE-EDITOR`（名称、时长） | 三页 |
| `beat` | 随项目由模板实例化 | `PAGE-EDITOR` | `PAGE-EDITOR`、`PAGE-FINAL` |
| `frame` | 随 beat 按 `frame_count` 实例化 | `PAGE-EDITOR`（仅 `content`） | Prompt 组装（不直接进 prompt 槽位，作为人写作依据） |
| `transition_rule` | 随 beat 预置 | `PAGE-EDITOR` 板尾（B5 只读） | `PAGE-FINAL` 衔接总表、后期合成 |
| `prompt_final` | M3 组装 | 不可人工编辑 | 生成引擎、飞书导出 |
| `video_url` | M4 生成成功 | 不可人工编辑 | `PAGE-EDITOR` 预览、`PAGE-FINAL` |

字段语义唯一来源：`PRD-001 §8`。

## 8. 信息优先级（What Users See First）

| 页面 | 第一眼 | 第二眼 | 第三眼 |
| --- | --- | --- | --- |
| 项目列表 | 项目名与完成度 | 总时长是否在区间内 | 行内动作 |
| 核心编辑器 | 五板结构与各板状态 | 当前板的宫格与板级槽位 | 只读 prompt 与板尾衔接 |
| 成片 | 完成度 n/5 | 分板视频 | 衔接总表与导出 |

原则：**结构先于内容，内容先于参数，参数先于导出。**

## 10. 无障碍与响应式（Accessibility & Responsive）

| 项 | 要求 |
| --- | --- |
| 键盘可达 | Tab 顺序 = 视觉顺序；宫格 Tab 顺序严格左→右（呼应 R4） |
| 焦点可见 | 所有可交互元素有清晰焦点态 |
| 语义标签 | 板为 `section`，板头为标题层级；宫格为带 `label` 的表单域 |
| 断点 | ≥1440px 三区完整；1024–1440px 左侧导航可收起为图标；<1024px 提示使用桌面端（创作场景为桌面优先） |
| 收起导航 | 收起后仍保留三个入口，不得隐藏任一入口 |
