# Backlog 与验收标准（V1.0 / P0）

> 依据：[`prd-seedance-tool.md`](./prd-seedance-tool.md) 正式版转写。
> 结构：P0 用户故事按 PRD **第 5 章能力（5.1–5.5）** 分组，每条故事标注所属**页面（11.1–11.4）**；验收标准全部为 Given/When/Then，强制字段与规则严格对齐 PRD **第 6 章（验收）、第 8 章（NFR）、第 11 章（页面原型）**。
> 优先级：V1.0 全部故事为 **P0**；V1.1 / V1.2 范围以 P1 / P2 概述（见第 7 节），本迭代不展开。
> 红线纪律：本 backlog 不含任何传统分镜相关故事（PRD 红线 R1）。

## 0. 全局红线验收（横切所有故事，CI 级）

### US-R1 禁止分镜入口 — P0
**故事**：作为产品负责人，我要求全站不存在任何"分镜"入口与镜头级实体，以守住工业化约束。

- Given V1.0 全部页面（11.1–11.4）与 API，When 遍历 UI 文案、路由、菜单与接口清单，Then 不存在"分镜"字样的入口/按钮/页面，不存在镜头级增删接口与景别/机位/运镜字段（PRD AC-6.8）。

### US-R2 衔接绝不进 AI — P0
**故事**：作为产品负责人，我要求衔接、备注、节拍名称永不进入 Prompt 与生成请求，以保证生成输入纯净。

- Given 任一节拍的衔接/备注/节拍名称填入唯一标记字符串，When 查看 Prompt 面板全文并抓取生成 API 请求体，Then 两处均不包含该标记（PRD AC-6.4）。
- Given 组装器代码，When 运行 CI 测试套件，Then 存在覆盖上述断言的自动化用例且必须通过（PRD 第 8 章可观测项）。

### US-R3 所见即所发 — P0
**故事**：作为创作者，我要求提交给 API 的 Prompt 与面板展示完全一致，以便调试可信。

- Given 一次已完成的生成任务，When 对比其 PromptSnapshot 与当时面板展示全文，Then 二者逐字一致，无面板外隐藏注入（PRD 红线 R5）。

## 1. 能力 5.1 项目与自动五节拍（页面 11.1 项目列表页 / 11.2 编辑页）

### US-511 新建项目（强制字段校验） — P0 ｜页面 11.1
**故事**：作为创作者，我要通过强制字段表单新建项目，以便项目具备生成所需的全局信息。

- Given 新建项目弹窗，When 未填任一强制字段（项目名称/题材/画幅/单集目标时长/画风风格词/主角形象描述）点击创建，Then 创建被阻止并逐项标红提示。
- Given 全部强制字段已填（画幅默认 9:16），When 点击创建，Then 项目创建成功并直接进入编辑页（11.2）。

### US-512 自动五节拍初始化 — P0 ｜页面 11.2
**故事**：作为创作者，我要新项目自动生成五个预命名节拍，以便按工业模板直接开填。

- Given 项目创建成功，When 进入编辑页，Then 3 秒内左导航呈现 5 个节拍，默认命名依次为 钩子/冲突/升级/反转（高潮）/悬念钩子，且各节拍时长默认预填为 目标时长/5（PRD AC-6.1、5.1.2）。
- Given 任一项目，When 检查数据库与全部 API，Then 节拍数恒等于 5，不存在增删节拍的接口与 UI（PRD 红线 R3）。

### US-513 项目列表管理 — P0 ｜页面 11.1
**故事**：作为创作者，我要在项目列表查看进度并管理项目，以便多项目并行。

- Given 已有若干项目，When 打开项目列表，Then 每张项目卡显示名称、题材、画幅、目标时长、更新时间与五节拍状态点阵（语义与左导航状态点一致，PRD 11.1）。
- Given 一个项目，When 执行删除，Then 需输入项目名二次确认；确认后项目消失且其队列中任务被取消（PRD 12.8）。
- Given 一个项目，When 重命名，Then 列表与编辑页顶栏同步更新。

## 2. 能力 5.2 节拍编辑（页面 11.2 编辑页）

### US-521 左侧五项导航 — P0 ｜页面 11.2
**故事**：作为创作者，我要通过左侧固定五项导航在节拍间切换，以便始终掌握全集结构与状态。

- Given 编辑页，When 页面加载完成，Then 左侧固定显示 5 项导航（不多不少），每项含节拍名称与状态点（未填/已填/生成中/已生成/失败）（PRD 5.2.1、11.2）。
- Given 正在编辑节拍二，When 点击导航中的节拍四，Then 当前内容先自动保存再切换；保存失败则阻断切换并提示（PRD 12.1）。
- Given 编辑页获得焦点，When 按键盘 ↑/↓，Then 切换到相邻节拍（PRD 12.1）。

### US-522 节拍卡强制字段编辑与校验 — P0 ｜页面 11.2
**故事**：作为创作者，我要按强制字段表填写节拍卡，以便节拍达到可生成的就绪态。

- Given 一个空节拍，When 查看节拍卡，Then 呈现 PRD 5.2.2 表全部字段：节拍名称（预填）、剧情概要、情绪基调（7 选 1）、画面宫格、时长（预填）、衔接、备注；项目级字段（风格词/主角/画幅）只读展示不可重复填写。
- Given 剧情概要、情绪基调、任一激活宫格描述、时长中任一为空，When 查看该节拍，Then 导航状态点为"未填"，且"生成本节拍"按钮置灰并列出缺失字段（PRD AC-6.2、12.4）。
- Given 全部必填字段完成，When 校验通过，Then 状态点变"已填"，生成按钮可用。

### US-523 画面宫格 3/2 — P0 ｜页面 11.2
**故事**：作为创作者，我要以 3 宫格或 2 宫格白话描述节拍画面，以替代传统分镜完成画面结构化。

- Given 一个节拍，When 查看宫格控件，Then 仅有 3 宫格 / 2 宫格两档，无其他数量选项（PRD 红线 R4、AC-6.3）。
- Given 3 宫格且三格均已填写，When 切换为 2 宫格，Then 出现轻提示"第 3 格已保留为草稿，不参与生成"，第 3 格折叠为草稿胶囊，其内容退出 Prompt 组装（PRD 5.2.3、12.2）。
- Given 上述状态，When 切回 3 宫格，Then 第 3 格内容静默恢复并重新参与组装。
- Given 宫格各格，When 查看字段构成，Then 每格仅有"画面描述"一个文本字段，无景别/机位/运镜等专业字段（PRD 红线 R1）。

### US-524 衔接字段（人读不进 AI） — P0 ｜页面 11.2
**故事**：作为创作者，我要用衔接字段记录节拍间承接关系供自查，同时确信它不会污染生成。

- Given 节拍卡，When 查看衔接输入框，Then 旁边固定灰字标识"仅供人读，不进入 AI"（PRD 11.2）；节拍五的占位文案提示"指向下一集悬念"（PRD 5.2.4）。
- Given 衔接字段填入任意内容，When 查看 Prompt 面板与提交请求，Then 内容不出现（复用 US-R2 断言）。
- Given 衔接字段为空，When 校验节拍就绪度，Then 不阻塞提交（衔接为建议填写、非必填）。

### US-525 自动保存 — P0 ｜页面 11.2
**故事**：作为创作者，我要字段自动保存，以便不因意外操作丢失内容。

- Given 正在编辑任一字段，When 停止输入 2 秒，Then 内容防抖落库，页面显示"自动保存于 x 前"（PRD 5.2.5、11.2）。
- Given 断网状态下继续编辑，When 网络恢复，Then 本地暂存内容自动同步并提示成功；断网期间顶部黄条提示（PRD 12.9）。
- Given 保存链路正常，When 统计保存成功率，Then ≥99.9%（PRD 第 8 章）。

## 3. 能力 5.3 Prompt 实时组装（页面 11.2 编辑页右侧面板）

### US-531 实时组装面板 — P0 ｜页面 11.2
**故事**：作为创作者，我要右侧面板实时展示最终 Prompt 全文，以便所填即所得。

- Given 节拍卡任一参与组装字段（概要/情绪/宫格描述/时长/项目级字段）变更，When 变更发生，Then 面板在 500ms 内刷新为最新全文（PRD AC-6.5、第 8 章性能）。
- Given 面板全文，When 检查片段顺序，Then 符合 PRD 5.3.2 固定组装顺序：风格词→主角→画幅→情绪→概要→画面1→2(→3)，时长走 API 参数位不拼入文本。

### US-532 片段来源标注与联动高亮 — P0 ｜页面 11.2
**故事**：作为创作者，我要看清 Prompt 每段文字来自哪个字段，以便定位修改。

- Given Prompt 面板，When 查看各片段，Then 均带有来源标签（项目级/节拍/宫格）且标签不可关闭（PRD 5.3.3、12.3）。
- Given 某字段获得输入焦点，When 焦点变化，Then 面板中对应片段高亮联动（PRD 12.3）。

### US-533 Prompt 复制 — P0 ｜页面 11.2
**故事**：作为创作者，我要一键复制 Prompt 全文，以便外部调试。

- Given Prompt 面板，When 点击"复制 Prompt"，Then 全文进入剪贴板并出现成功 toast（PRD 5.3.4、12.3）。

### US-534 提交快照 — P0 ｜页面 11.2 / 11.3
**故事**：作为创作者，我要每次提交生成时固化 Prompt 快照，以便历史可溯可复现。

- Given 一次生成提交成功，When 之后任意修改节拍字段，Then 该任务的 PromptSnapshot 保持提交时刻原文不变（PRD 5.3.5、AC-6.9、第 9 章不可变规则）。
- Given 队列页任一历史任务，When 点击"查看快照"，Then 展示完整 Prompt 全文与参数（PRD 11.3）。

## 4. 能力 5.4 生成队列（页面 11.3 队列页 / 11.2 编辑页）

### US-541 单节拍提交生成 — P0 ｜页面 11.2
**故事**：作为创作者，我要在节拍卡一键提交本节拍生成，以便边填边试。

- Given 一个就绪节拍，When 点击"生成本节拍"，Then 按钮进入 loading，任务入队成功后左导航状态点变"生成中"；重复点击被防抖拦截（PRD 12.4）。
- Given 一个未就绪节拍，When 尝试提交，Then 按钮置灰且列出缺失字段，无任务产生（PRD 5.4.2）。

### US-542 批量生成全集 — P0 ｜页面 11.2 / 11.3
**故事**：作为创作者，我要一键提交全部就绪节拍，以便一次跑完整集。

- Given 5 个节拍中 3 个就绪，When 点击"生成全集"，Then 弹出确认框列出将提交的 3 个与将跳过的 2 个及其原因；确认后 3 个任务入队（PRD 5.4.3、12.4）。
- Given 5 个节拍全部就绪，When 确认批量提交，Then 5 个任务全部落库入队，队列页逐行可见（PRD AC-6.6）。

### US-543 队列状态机与可靠性 — P0 ｜页面 11.3
**故事**：作为创作者，我要队列持久化、状态实时、失败自动重试，以便无人值守跑片。

- Given 队列中有任务，When 后端服务重启，Then 任务不丢失并自动续跑（PRD AC-6.6、第 8 章可靠性）。
- Given 并发上限默认 2，When 队列含 5 个任务，Then 同时处于"生成中"的任务不超过 2 个（PRD 5.4.4）。
- Given 任务因限流失败，When 自动重试（指数退避，默认 3 次），Then 重试成功正常回填；队列行显示"第 n 次尝试"（PRD 5.4.4、11.3）。
- Given 任一任务状态变化，When 查看编辑页左导航与队列页，Then 状态在 5 秒内同步刷新（PRD 5.4.5、第 8 章）。

### US-544 失败归类与重投 — P0 ｜页面 11.3 / 11.2
**故事**：作为创作者，我要失败任务给出归类原因与建议动作，以便快速修复重投。

- Given 一个重试耗尽的失败任务，When 查看队列行与节拍卡错误条，Then 显示错误归类（鉴权/限流/内容拒绝/参数错误/服务异常之一）、可读中文说明与 [重投] 按钮（PRD 5.4.4、12.5）。
- Given 失败原因为"内容拒绝"，When 修改剧情概要或画面描述后点击重投，Then 以新 Prompt 生成新任务与新快照，成功后正常回填。

### US-545 重生成与历史回滚 — P0 ｜页面 11.4 / 11.2
**故事**：作为创作者，我要对已成功节拍重新生成并可回滚历史版本，以便择优。

- Given 一个已生成节拍，When 在成片页点击 ↻ 并二次确认，Then 新任务以当前字段提交，成功后新 Segment 替换为当前段，旧 Segment 保留于历史记录（PRD 5.4.6、12.6）。
- Given 节拍历史记录中的旧 Segment，When 点击"设为当前段"，Then 成片页该卡切换为旧视频（PRD 12.6）。

### US-546 成本记录 — P0 ｜页面 11.3 / 11.1
**故事**：作为创作者，我要看到每次生成的费用与项目累计消耗，以便控制成本。

- Given 一个完成任务，When 查看队列行，Then 显示该任务时长与费用估算（误差 ≤10%，PRD 第 8 章）；队列页顶部显示项目累计费用（PRD 11.3）。

### US-547 API Key 配置与安全 — P0 ｜页面 11.1（项目设置）
**故事**：作为创作者，我要配置我的 Seedance2.5 API Key 且确信它安全存储，以便任务能够执行。

- Given 未配置 Key 的项目，When 提交生成，Then 得到明确的"未配置/鉴权失败"提示与配置入口。
- Given 已配置 Key，When 检查前端页面源码、网络响应与日志输出，Then Key 明文不出现（服务端加密存储，PRD 第 8 章数据安全）。

## 5. 能力 5.5 成片页（页面 11.4）

### US-551 五段卡片展示 — P0 ｜页面 11.4
**故事**：作为创作者，我要按节拍顺序查看固定五张段卡，以便掌握整集成片进度。

- Given 项目部分节拍已生成，When 打开成片页，Then 固定显示 5 张卡（顺序=节拍序），已生成卡含内嵌可播放视频、时长、完成时间；未生成卡显示占位与"去编辑"入口（PRD 5.5.1、AC-6.7、11.4）。
- Given 节拍处于生成中，When 查看对应卡片，Then 显示"生成中"状态且随队列刷新（≤5s）。

### US-552 逐段下载与打包 — P0 ｜页面 11.4
**故事**：作为创作者，我要逐段或打包下载视频，以便交付下游剪辑。

- Given 一张已生成段卡，When 点击下载，Then 得到命名为 `项目名_节拍序号_节拍名.mp4` 的文件（PRD 5.5.2、11.4）。
- Given 5 段全部生成，When 点击"全部下载"，Then 得到含 5 个按规范命名视频的 zip。

### US-553 顺序连播预览 — P0 ｜页面 11.4
**故事**：作为创作者，我要按 1→5 顺序连播当前段，以便整体审看节奏。

- Given 5 段全部生成，When 点击"顺序连播"，Then 按节拍序连续播放，播放器标示当前节拍序号（PRD 5.5.3）。
- Given 部分节拍未生成，When 点击连播，Then 跳过缺失段并在界面提示缺口清单。

### US-554 拼接按钮占位（锁定态） — P0 ｜页面 11.4
**故事**：作为产品负责人，我要成片页预留"一键拼接"锁定按钮，以便版本边界对用户透明。

- Given 成片页，When 查看工具栏，Then "一键拼接"按钮存在但置灰锁定，标注"V1.1 开放"，点击仅出现版本说明气泡，不产生任何拼接行为（PRD 5.5.5、11.4、第 10 章版本纪律）。

## 8. P0 实施顺序建议（就绪度）

```
第一波（零依赖）：
  T1 工程脚手架 + 第9章数据模型落库（Project/Beat/GridCell/PromptSnapshot/GenerationJob/Segment）

第二波：
  US-511/512/513（项目与五节拍） ← T1
  Prompt 组装器内核 + 硬排除清单 + CI 断言（US-R2/R3、US-531 底层） ← T1
第三波：
  US-521~525（编辑页） ← 第二波
  US-541/543（单发 + 队列内核） ← T2 + 组装器
第四波：
  US-531~534（面板交互层）、US-542/544/545/546/547
第五波：
  US-551~554（成片页）、US-R1 全站终检
```

**立即可动工**：T1（脚手架与数据模型）、T2（Seedance2.5 多镜头语法 spike）。
