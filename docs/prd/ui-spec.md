# UI 规格（UI Specification）

- 文档编号：`PRD-005`
- 版本：`v1.0`
- 状态：**BASELINE**
- 归属：Wave 1 / Slot P2 / Cycle W1
- 上游：[`prd.md`](./prd.md)、[`information-architecture.md`](./information-architecture.md)、`METH-001 §10.2`

> **UI 第一原则**：**没有的能力，就没有控件。**
> 废弃项不做"隐藏"或"高级选项"，直接不存在（`METH-001 §3` 判定规则）。
> 布局锁：左侧导航 + 顶部栏 + 主编辑区；页面锁：项目列表 / 核心编辑器 / 成片。

## 1. 布局骨架（Layout Skeleton）

```
┌───────────────────────────────────────────────────────────────────────┐
│ TopBar  h=56                                                          │
├──────────────┬────────────────────────────────────────────────────────┤
│ LeftNav      │ Main                                                   │
│ w=200        │ 内容最大宽 1080，居中，左右留白 ≥24                      │
│ (可收起 64)   │                                                        │
└──────────────┴────────────────────────────────────────────────────────┘
```

| 元素 | 规格 |
| --- | --- |
| 栅格 | 12 列，间距 16，主区内容最大宽 1080 |
| 间距标尺 | 4 / 8 / 12 / 16 / 24 / 32 |
| 圆角 | 卡片 12，控件 8，标签 999 |
| 层级 | 卡片 1 层阴影；弹层 2 层阴影；不使用多层嵌套卡片 |
| 字号 | 页面标题 20/600；板头 16/600；正文 14/400；辅助 12/400 |

### 1.1 语义色（Semantic Tokens）

| Token | 用途 | 建议值 |
| --- | --- | --- |
| `--fg-primary` | 主文本 | `#1F2329` |
| `--fg-secondary` | 辅助文本、占位提示 | `#8F959E` |
| `--bg-page` | 页面底色 | `#F5F6F7` |
| `--bg-card` | 卡片底色 | `#FFFFFF` |
| `--accent` | 主动作、当前导航 | `#3370FF` |
| `--state-ok` | 可生成 / 已生成 / 已保存 | `#00B42A` |
| `--state-warn` | 时长区间警示 / 待补全 | `#FF8800` |
| `--state-error` | 超 30s / 生成失败 / 校验拦截 | `#F53F3F` |
| `--state-running` | 排队中 / 生成中 | `#3370FF` |
| `--bg-locked` | 只读/锁定字段底色 | `#F2F3F5` |

**锁定态视觉约定**：所有只读字段（节拍名、组号、宫格数、固定前缀、B5 衔接、`prompt_final`）统一用 `--bg-locked` + 锁形图标 + `aria-readonly`，让"不可改"一眼可见。

| 项 | 规格 |
| --- | --- |
| 结构 | 产品名（顶部）+ 3 个入口 + 底部占位 |

## 3. 顶部栏（TopBar）

三页共用骨架，内容随页面变化。

| 页面 | 左侧 | 中部 | 右侧 |
| --- | --- | --- | --- |
| 项目列表 | 「项目列表」 | 搜索框 | 主按钮「新建项目」 |
| 核心编辑器 | 项目名（就地可编辑）| 总时长徽标 + 保存态 | 「生成整集」（次要）、「去成片」（文本按钮） |
| 成片 | 「成片」+ 项目名 | 完成度徽标 `n/5` | 主按钮「导出飞书」 |

### 3.1 总时长徽标

| 状态 | 条件 | 呈现 |
| --- | --- | --- |
| 正常 | 70 ≤ 总时长 ≤ 90 | `--state-ok`：`总时长 88s` |
| 偏短 | < 70 | `--state-warn`：`总时长 62s · 低于 70s` |
| 偏长 | > 90 | `--state-warn`：`总时长 96s · 超过 90s` |

徽标 hover 展开 5 板时长明细。区间越界**不阻断编辑**，但阻断成片页"可交付"标记（`AC-F2-7`、`AC-F6-5`）。

### 3.2 保存态

`保存中…` → `已保存 · HH:mm` → 失败时 `--state-error`：`保存失败 · 重试`（内容保留在输入框中，`AC-F2-10`）。

## 5. 页面 2：核心编辑器

### 5.1 节拍板卡片（BoardCard）

```
┌───────────────────────────────────────────────────────────────┐
│ B1  开篇钩子   G1   0–8s   时长 [ 8 ] s 🔒节拍锁定   ● 可生成   │  ← 板头
├───────────────────────────────────────────────────────────────┤
│ 本段情绪 * [骤然炸裂的震惊，压迫感在三秒内拉满            ]     │
│ 镜头节奏 * [极快切入，冲击—反应—环境三段递进            ]     │  ← 板级槽位
│ 剧情核心 * [婚宴上被当众甩出亲子鉴定，新娘身份瞬间坍塌    ]     │
├───────────────────────────────────────────────────────────────┤
│ 节拍帧（左 → 右，顺序锁定）                                    │
│ ┌ 冲击 ─────┐ ┌ 反应 ─────┐ ┌ 环境 ─────┐                    │  ← 宫格区
│ │           │ │           │ │           │                    │
│ └───────────┘ └───────────┘ └───────────┘                    │
├───────────────────────────────────────────────────────────────┤
│ Prompt（只读）🔒                                     [复制]    │  ← Prompt 面板
│ 漫剧厚涂画风，高清8K... 人物五官稳定无漂移...，骤然炸裂的…      │
├───────────────────────────────────────────────────────────────┤
│ 本板结束 → 进入下一板： [音频预接 ▾]            [ 生成本板 ]    │  ← 板尾
└───────────────────────────────────────────────────────────────┘
```

板卡片之间只有 24px 间距，**不放任何连接线控件**——板间关系由板尾衔接选择器表达，不由画布连线表达。

### 5.2 板头（BoardHeader）

| 元素 | 规格 |
| --- | --- |
| 板序徽标 | `B1`–`B5`，`--accent` 徽标 |
| 节拍名 | 16/600 文本 + 锁图标，**不可编辑** |
| 组号 | `G1`–`G5`，辅助色，不可编辑 |
| 时间位 | `0–8s`，辅助色 |
| 时长输入 | 数字输入 + `s` 后缀；步进 1；范围提示"≤ 30s" |
| 状态徽章 | 待补全（warn）/ 可生成（ok）/ 排队中（running）/ 生成中（running，带进度）/ 已生成（ok）/ 生成失败（error） |
| 折叠 | 允许折叠板体（仅视觉），折叠不改变顺序、不改变数据 |

**时长错误态**：输入 >30 时输入框转 `--state-error`，下方提示「单板时长不得超过 30 秒（组内时长分配由 AI 负责）」，同时状态徽章转为 `待补全`，生成按钮禁用（`AC-R3-1`）。

### 5.3 板级槽位（BoardSlots）

| 字段 | 控件 | 占位提示 | 上限 |
| --- | --- | --- | --- |
| 本段情绪 | 单行/自适应文本域 | 「这一段的宏观情绪定调，例如：骤然炸裂的震惊」 | 120 字符 |
| 镜头节奏 | 单行/自适应文本域 | 「只写节奏感，例如：快切递进 / 先慢后紧（切几刀、每刀多长由 AI 决定）」 | 120 字符 |
| 剧情核心 | 文本域 2 行 | 「一句话说清这一段推进了什么」 | 160 字符 |

三者均带 `*` 必填标记，失焦保存，字数达 90% 时显示计数。

**节奏字段软提示**：命中"秒/s/第几个画面/几刀"等模式时，字段下方出现提示「该字段只接受节奏形容，具体切分由 AI 决定」，**不阻断保存**（`AC-F2-11`）。

### 5.4 宫格区（FrameGrid）

| 项 | 规格 |
| --- | --- |
| 列数 | B1–B4：3 列等宽；B5：2 列等宽（居中，与 3 列同总宽） |
| 单格 | 最小高 120，卡片内嵌浅色底；顶部为语义标签（只读徽标） |
| 输入 | 多行文本域，上限 200 字符，失焦保存 |
| 语义标签 | B1：冲击 / 反应 / 环境；B2–B4：递进 ①②③；B5：抛出悬念 / 最高势能处切断 |
| 序号 | 左上角显示 `帧 1 / 帧 2 / 帧 3`，只读 |
| Tab 顺序 | 严格左→右（`AC-U-6`） |
| 空态 | 灰色占位示例文案（`--fg-secondary`，不入库） |

**宫格内禁止出现的元素（逐条对齐红线）：**

| 禁止元素 | 法源 |
| --- | --- |
| 拖拽手柄、上移/下移、排序按钮 | R4 |
| 时长输入、时间码 | 废弃项 D3 |
| 转场/过渡选择器 | R1、D4 |
| 「添加宫格 / 删除宫格」 | R7 |
| 子画面、镜号、镜别字段 | D1 |
| 「设为主帧」 | `METH-002 §3` |

### 5.5 Prompt 面板（PromptPanel）

| 项 | 规格 |
| --- | --- |
| 容器 | `--bg-locked` 底、锁图标、右上「复制」 |
| 渲染 | 五槽位分段着色：固定前缀（灰）→ 情绪 → 时长 → 节奏 → 剧情核心；hover 显示槽位名 |
| 只读 | 无输入框、无编辑按钮（`AC-F3-7`） |
| 缺槽位 | 缺失位置显示灰色占位 `[缺：剧情核心]`，面板顶部提示缺失项 |
| 更新 | 槽位变更后 ≤200ms 重算（`AC-N-2`） |
| 折叠 | 默认折叠为 2 行，可展开全文 |
| 拦截态 | 命中转场词时，命中词高亮 `--state-error`，提示「prompt 中不得包含转场描述：卡点硬切。转场只在后期合成阶段设置。」 |

### 5.6 板尾（BoardFooter）

| 元素 | 规格 |
| --- | --- |
| 衔接标题 | `本板结束 → 进入下一板`（B5 为 `本集结束 → 进入下一集`） |
| 衔接选择器 | 多选下拉，最多 2 项；选项恰为 5 项封闭枚举，选项后附一行语义说明 |
| 已选呈现 | 标签形式（如 `卡点硬切` + `BGM 升调截断`），可移除 |
| 阶段标注 | 选择器右侧常驻辅助文案「仅后期合成生效，不进入 AI prompt」 |
| B5 特例 | 只读标签 `无转场 / 黑屏截断` + 锁图标，无下拉（`AC-F5-6`） |
| 待法源确认 | B3 若为 `pending_canon`，标签后附 `待法源确认` 徽标 + tooltip 指向 `PRD-001 §12 O-P2-1` |
| 生成按钮 | 主按钮「生成本板」；禁用时 tooltip 列出全部阻断原因 |
| 结果区 | 生成成功后在板尾展开视频缩略图 + 播放 + 下载 + 「重新生成」 |

**选择器禁止**：无自由输入、无"自定义转场"、无"AI 推荐衔接"（`AC-R2-1`、`AC-F5-2`）。

### 5.7 生成状态呈现

| 状态 | 板头徽章 | 板尾按钮 | 其他板 |
| --- | --- | --- | --- |
| 待补全 | warn `待补全` | 禁用 + 原因 tooltip | 不受影响 |
| 可生成 | ok `可生成` | 「生成本板」可用 | 不受影响 |
| 排队中 | running `排队中` | 「排队中…」禁用 | 可正常编辑（`AC-F4-4`） |
| 生成中 | running `生成中` + 进度 | 「生成中…」禁用 | 可正常编辑 |
| 已生成 | ok `已生成` | 「重新生成」 | 不受影响 |
| 生成失败 | error `生成失败` | 「重试」+ 原因链接 | 不受影响 |

「生成整集」按钮：点击后弹确认，说明「将按 B1→B5 依次发起 5 次独立生成」；不合规板在确认弹层中列出并标注将被跳过（`AC-F4-7`）。

## 8. 文案表（Copy Deck）

术语一律取 `METH-002` 标准词。

| 场景 | 文案 |
| --- | --- |
| 新建说明 | 新建后自动创建 5 块锁定节拍板：开篇钩子 / 矛盾建立 / 打压升级 / 反转蓄力 / 断集留客。 |
| 节拍名只读 | 五节拍结构已锁定，不可增删或改序。 |
| 宫格只读 | 宫格数由板序决定：前四板 3 格，第五板 2 格。 |
| 帧序说明 | 节拍帧按左 → 右顺序读取，不支持重排。 |
| 时长超限 | 单板时长不得超过 30 秒（组内时长分配由 AI 负责）。 |
| 总时长偏短 | 总时长 {n}s，低于建议区间 70–90s。 |
| 总时长偏长 | 总时长 {n}s，超过建议区间 70–90s。 |
| 节奏字段提示 | 该字段只接受节奏形容，具体切分由 AI 决定。 |
| 生成禁用（缺项） | 还需补全：{缺失项列表}。 |
| 生成禁用（时长） | 第 {n} 板时长超过 30 秒，请先调整。 |
| 转场词拦截 | prompt 中不得包含转场描述：{命中词}。转场只在后期合成阶段设置。 |
| 前缀只读 | 固定前缀由系统统一维护，用于统一画风与人物一致性。 |
| 衔接标题 | 本板结束 → 进入下一板 |
| 衔接阶段说明 | 仅后期合成生效，不进入 AI prompt。 |
| B5 衔接 | 无转场 / 黑屏截断（已锁定） |
| 待法源确认 | 该衔接取值待方法论确认（O-P2-1）。 |
| 整集生成确认 | 将按 B1 → B5 依次发起 5 次独立生成。 |
| 复用说明 | 继承结构、节拍语义、宫格数、时长与 AI 参数；清空画面内容、prompt 与视频结果。 |
| 缺片提示 | 还缺 {板号列表} 未生成，暂不可标记可交付。 |
| 导出成功 | 已导出到飞书。 |
| 列表空态 | 还没有项目。新建后会自动生成 5 块锁定节拍板。 |
| 成片空态 | 暂无成片。先在核心编辑器生成 5 板视频。 |

**文案禁令**：任何界面文案不得出现 `METH-002 §8` 禁用词；描述"这一段的画面"时统一用"节拍帧 / 宫格"，描述生成单元时统一用"板 / 节拍板"。

## 9. 交互规则（Interaction Rules）

| # | 规则 |
| --- | --- |
| `IX-1` | 所有编辑均为失焦保存，无"保存"按钮；破坏性操作（复用/重新生成）需二次确认 |
| `IX-2` | 校验反馈就地显示（字段下方），不使用全局 toast 承载阻断原因 |
| `IX-3` | 禁用按钮必须可 hover 出原因，不得静默禁用（`NFR-6`） |
| `IX-4` | 生成中的板仅锁定其提交入口，不锁定其他板的编辑 |
| `IX-5` | 键盘：`Tab` 左→右、`Cmd/Ctrl+S` 触发立即保存、`Esc` 关闭弹层；不提供任何改变帧序的快捷键 |
| `IX-6` | 长列表与长文本不截断关键信息（板号、节拍名、时长必须完整可见） |
| `IX-7` | 首屏优先渲染 5 板骨架（板头 + 宫格框），内容异步填充，保障 `NFR-1` ≤1s 可交互 |
| `IX-8` | 视频预览默认不自动播放，避免多板同时播放 |
