## 1. 背景

AI 短剧（竖屏、单集 1–3 分钟、强钩子快节奏）的生产瓶颈不在模型能力，而在**生产组织方式**：

1. 创作者用传统影视的"剧本 → 分镜表 → 逐镜生成"流程套 AI 生产，分镜粒度过细、专业字段过多，填表成本远高于产出价值；
2. 提示词靠人肉拼写，同一集内风格、主角形象漂移，返工率高；
3. 生成过程无队列、无状态管理，"抽卡"式重试导致产能不可预测；
4. 节拍之间的衔接逻辑（转场、承接关系）被写进提示词，反而污染生成结果。

Seedance2.5 具备**原生多镜头叙事生成能力**：一次生成即可在单段视频内完成多个画面的自然切换。这意味着传统"分镜"这一中间层可以被彻底移除——生产的最小单元可以直接上移到"节拍"。

本产品据此重构 AI 短剧生产流：**以固定五节拍结构为工业模板，以节拍为唯一生成单元，以宫格画面描述替代传统分镜，以实时组装的 Prompt 连接创作与生成**。

## 2. 定位

**一句话定位**：Seedance2.5 专属的 AI 短剧节拍板工业化生产工具——填五张节拍卡，出五段视频，组一集短剧。

- **Seedance2.5 专属**：不做多模型适配，深度榨取 Seedance2.5 的多镜头叙事、主体稳定等原生能力；
- **节拍板**：产品唯一中枢是五节拍结构，不存在剧本工作台、分镜表、剪辑时间线等平行中枢；
- **工业化**：结构固定（5 节拍 × 3/2 宫格）、字段强制、规则收紧（衔接不进 AI、禁止分镜入口），用约束换稳定产能；
- **生产工具**：目标是"稳定出片"，不是创意画布，不追求自由度。

**反定位（本产品不是什么）**：不是通用视频生成客户端，不是分镜/故事板软件，不是视频剪辑器，不是剧本写作工具。

## 3. 范围

### 3.1 V1.0 范围内（本迭代）

| 编号 | 能力 | 摘要 |
|---|---|---|
| 5.1 | 项目与自动五节拍 | 新建项目自动创建 5 个节拍，结构固定 |
| 5.2 | 节拍编辑 | 编辑页左侧 5 项节拍导航；节拍卡强制字段；画面宫格 3 或 2；衔接字段（人读） |
| 5.3 | Prompt 实时组装 | 节拍字段实时组装为最终 Prompt，可见、可复制、可快照；衔接绝不进入 |
| 5.4 | 生成队列 | 节拍为生成单元，单发/批量入队，状态机 + 持久化 + 自动重试 |
| 5.5 | 成片页 | 5 段卡片按节拍顺序展示，逐段预览与下载 |

### 3.2 V1.0 范围外（明确不做）

- **任何形式的分镜功能**：无分镜页面、无分镜按钮、无镜头级增删、无景别/机位/运镜等专业分镜字段（红线，见第 7 章）；
- 一键拼接成片（V1.1）、题材模板（V1.1）；
- 多人协作、权限、评论（V1.2）；
- 剧本编辑器/导入、角色资产库、剪辑时间线、配音/BGM、发行与投流；
- 节拍数量自定义、宫格数量自定义（仅 3 或 2）。

## 4. 用户

V1.0 面向**单人创作者 / 单人操作的小团队**（无协作功能，V1.2 引入协作）。

| 用户画像 | 描述 | 核心诉求 |
|---|---|---|
| AI 短剧个人创作者 | 独立完成选题到成片，日更压力大 | 结构化模板降低决策成本，稳定出片 |
| 短剧工作室生成岗 | 团队中负责"出素材"的操作员 | 批量提交、失败可控、结果可交付下游剪辑 |
| MCN/内容机构试产线 | 评估 AI 短剧产能的试点人员 | 流程可复制、产能可预测、成本可核算 |

用户前置条件：持有有效的 Seedance2.5 API Key；具备基本短剧叙事常识（工具通过五节拍默认结构降低门槛）。

## 5. P0 能力（V1.0 功能需求）

### 5.1 项目与自动五节拍

- **5.1.1 新建项目**：强制字段——项目名称、题材（自由文本，V1.1 升级为模板选择）、画幅（默认 9:16）、单集目标时长、全局画风风格词、主角形象描述。强制字段未填不可创建。
- **5.1.2 自动五节拍**：项目创建成功后**自动生成 5 个节拍**，默认命名与叙事定位预填：
  1. 节拍一「钩子」——3 秒抓住观众的开场冲突；
  2. 节拍二「冲突」——矛盾正面展开；
  3. 节拍三「升级」——冲突加码、压力递增；
  4. 节拍四「反转/高潮」——情节反转或情绪顶点；
  5. 节拍五「悬念钩子」——收尾留钩，导向下一集。

  节拍名称可改，**节拍数量固定为 5，不提供增删入口**（红线）。
- **5.1.3 项目列表**：展示项目卡（名称、题材、画幅、更新时间、五节拍完成度点阵），支持打开、重命名、删除（二次确认）。

### 5.2 节拍编辑（编辑页）

- **5.2.1 左侧五项导航**：编辑页左侧为**固定 5 项导航**，对应节拍一至五；每项显示节拍名称与状态点（未填 / 已填 / 生成中 / 已生成 / 失败）；点击切换中部编辑区，切换前自动保存当前节拍。
- **5.2.2 节拍卡强制字段**（进入 Prompt 组装的字段以 ● 标记，不进入的以 ○ 标记）：

| 字段 | 必填 | 进 Prompt | 说明 |
|---|---|---|---|
| 节拍名称 | 是（默认预填） | ○ | 仅用于导航与成片页标识 |
| 剧情概要 ● | 是 | ● | 本节拍发生什么，1–3 句 |
| 情绪基调 ● | 是 | ● | 单选：紧张/温情/悬疑/爆笑/愤怒/悲伤/燃 |
| 画面宫格 ● | 是（每格必填） | ● | 见 5.2.3 |
| 时长（秒） ● | 是（默认按目标时长/5 预填） | ● | 该节拍视频段时长 |
| 衔接 ○ | 否（建议填写） | **○ 绝不进入** | 与下一节拍的承接说明，见 5.2.4 |
| 备注 ○ | 否 | ○ | 自由备忘 |

  项目级字段（全局画风风格词、主角形象描述、画幅）自动注入每个节拍的 Prompt，节拍卡内只读展示、不重复填写。
- **5.2.3 画面宫格（3 或 2）**：每个节拍的画面由**宫格**构成，仅两种规格——**3 宫格或 2 宫格**，节拍级切换，不开放其他数量。每格填写一段"画面描述"（该格画面里发生什么、看到什么），按格序对应 Seedance2.5 原生多镜头能力在**一次生成**内完成画面切换。宫格从 3 切 2：第 3 格内容保留为草稿、不参与 Prompt 组装与生成；切回 3 恢复。**宫格是本产品对"分镜"的替代物**：无景别、无机位、无运镜字段，只有白话画面描述。
- **5.2.4 衔接字段**：描述本节拍与下一节拍如何承接（如"接下一拍：镜头黑场后女主已在医院"）。用途：创作者自查连贯性；V1.1 一键拼接时作为转场参考。**该字段在任何情况下不进入 Prompt、不出现在生成 API 请求中**（红线，需自动化断言覆盖）。节拍五的衔接字段文案提示为"指向下一集悬念"。
- **5.2.5 自动保存**：所有字段变更 2 秒内防抖自动保存；切换导航、离开页面前强制落库；断网期间本地暂存，恢复后提示同步。

### 5.3 Prompt 实时组装

- **5.3.1 实时组装面板**：编辑页右侧常驻"Prompt 面板"，展示当前节拍的**最终 Prompt 全文**。任一参与组装的字段变更后，面板在 **500ms 内**刷新。
- **5.3.2 组装规则**（顺序固定，V1.0 不开放自定义模板）：

```
[全局画风风格词] + [主角形象描述] + [画幅指令]
+ [情绪基调] + [剧情概要]
+ [画面1描述] → [画面2描述] (→ [画面3描述])   // 按宫格序，采用 Seedance 多镜头语法
+ [时长参数（API 参数位，不拼入文本）]
```

- **5.3.3 来源可辨**：面板中各片段以来源标签着色（项目级 / 节拍级 / 宫格），使用者可一眼看出每段文字来自哪个字段。
- **5.3.4 可复制**：一键复制 Prompt 全文（供外部调试）。
- **5.3.5 快照**：每次提交生成时，当刻 Prompt 全文与参数固化为**快照**存入生成记录，后续修改字段不影响历史快照。
- **5.3.6 负面清单断言**：组装器对"衔接、备注、节拍名称"字段做**硬排除**——即使代码回归，单元测试须断言这三个字段的内容不出现在 Prompt 与 API 请求体中。

### 5.4 生成队列

- **5.4.1 生成单元**：一个节拍 = 一个生成任务 = 一段视频。无镜头级任务（红线：禁止分镜入口）。
- **5.4.2 就绪校验**：提交前校验强制字段齐备（5.2.2 表）；未就绪节拍不可提交，按钮置灰并提示缺失项。
- **5.4.3 单发与批量**：节拍卡内"生成本节拍"单发；编辑页顶部"生成全集"批量提交所有就绪节拍（跳过未就绪并列出原因）。
- **5.4.4 队列与状态机**：任务状态 `排队中 → 生成中 → 成功 / 失败`；队列持久化（服务重启不丢）；并发上限可配（默认 2）；失败自动重试（默认 3 次，指数退避）；3 次仍失败进入"失败"态，展示归类错误（鉴权 / 限流 / 内容拒绝 / 参数错误 / 服务异常）与建议动作。
- **5.4.5 状态回显**：编辑页左导航状态点与队列页实时刷新（延迟 ≤5s，轮询或推送均可）。
- **5.4.6 重生成**：已成功节拍可再次提交，新结果**替换为当前段**，旧结果保留在该节拍的历史记录中（含 Prompt 快照），可回滚设回当前段。
- **5.4.7 成本记录**：每任务记录时长与费用估算，项目页汇总累计消耗。

### 5.5 成片页

- **5.5.1 五段卡片**：成片页按节拍顺序展示**固定 5 张段卡**，每卡包含：节拍序号与名称、状态、当前段视频（内嵌播放）、时长、生成完成时间。未生成的节拍显示占位卡与"去编辑"入口。
- **5.5.2 逐段下载**：单卡下载对应视频文件（命名 `项目名_节拍序号_节拍名.mp4`）；"全部下载"打包 zip。
- **5.5.3 顺序连播预览**：按 1→5 顺序连续播放当前段（简单串播，不做剪辑处理）。
- **5.5.4 重生成入口**：卡片提供"重新生成"（用当前字段重投）与"去编辑"（跳回编辑页该节拍）。
- **5.5.5 拼接留位**：页面预留"一键拼接"按钮位，V1.0 置灰并标注"V1.1 开放"。

## 6. 验收（V1.0 整体验收标准与强制规则）

以下为版本级验收断言（用户故事级 Given/When/Then 见 backlog 文档）：

- **AC-6.1 自动五节拍**：新建项目成功后 3 秒内，编辑页呈现 5 个预命名节拍；数据库中该项目节拍数恒等于 5；不存在任何增删节拍的 UI 与 API。
- **AC-6.2 强制字段**：5.2.2 表中必填字段任一为空时：该节拍不可提交生成；导航状态点显示"未填"。
- **AC-6.3 宫格约束**：宫格规格取值仅 {3, 2}；切 2 后第 3 格内容不出现在 Prompt；切回 3 内容恢复。
- **AC-6.4 衔接不进 AI**：对任意节拍任意内容，Prompt 面板全文与生成 API 请求体中均不包含衔接、备注、节拍名称字段内容；此断言有自动化测试覆盖并纳入 CI。
- **AC-6.5 Prompt 实时性**：参与组装字段变更后 500ms 内面板刷新；组装顺序符合 5.3.2。
- **AC-6.6 队列可靠性**：批量提交 5 任务全部落库；服务重启后队列任务不丢失并续跑；限流失败自动重试后成功率可观测。
- **AC-6.7 成片页完整性**：5 段全部生成后，成片页 5 卡齐备、可播放、可下载，顺序与节拍序一致。
- **AC-6.8 禁止分镜入口**：全站（UI 文案、路由、菜单、API）不存在"分镜"入口与镜头级实体；代码评审 checklist 含此项。
- **AC-6.9 快照可溯**：任一历史生成记录可查看其提交时刻的完整 Prompt 与参数。

## 7. 红线（不可妥协规则）

| # | 红线 | 说明 |
|---|---|---|
| R1 | **禁止分镜入口** | 产品任何位置不得出现分镜页面/按钮/字段/实体；不得提供镜头级增删；宫格是唯一的画面结构化方式 |
| R2 | **衔接绝不进 AI** | 衔接（及备注、节拍名称）永不进入 Prompt 与生成 API 请求；以自动化测试固化 |
| R3 | **节拍数固定 5** | V1.0 不提供任何增删节拍能力（题材模板对结构的调整属 V1.1 议题） |
| R4 | **宫格仅 3 或 2** | 不开放 1、4 或自定义宫格数 |
| R5 | **Prompt 所见即所发** | 提交给 API 的文本必须与 Prompt 面板展示一致，禁止面板外隐藏注入；系统性前后缀也须在面板中可见 |
| R6 | **Seedance2.5 专属** | V1.x 不做多模型适配层暴露给用户 |
| R7 | **不做剪辑器** | 成片页只做展示/下载/串播（V1.1 增加一键拼接），不引入轨道、裁剪等剪辑概念 |

## 8. NFR（非功能需求）

| 类别 | 指标 |
|---|---|
| 性能 | Prompt 组装刷新 ≤500ms；编辑页首屏可交互 ≤2s；队列状态刷新延迟 ≤5s |
| 可靠性 | 生成任务持久化，服务重启零丢失；字段自动保存成功率 ≥99.9%；失败任务自动重试默认 3 次 |
| 数据安全 | Seedance API Key 仅存服务端并加密，前端与日志不可见明文；视频访问走签名 URL |

| 成本 | 项目级累计消耗实时可见；单任务费用估算误差 ≤10% |

## 9. 数据

### 9.1 实体与关系

```
Project 1 ──── 5 Beat（固定五条，级联创建/删除）
Beat    1 ──── 3|2 GridCell（画面格，规格 3 或 2）
Beat    1 ──── n GenerationJob（生成任务）
GenerationJob 1 ──── 1 PromptSnapshot（提交时刻快照）
GenerationJob 1 ──── 0..1 Segment（成功产出的视频段）
Beat    1 ──── 0..1 currentSegment（当前段指针，指向某个 Segment）
```

### 9.2 关键字段

- **Project**：`id, name, genre, aspect_ratio(默认9:16), target_duration_s, style_keywords, protagonist_desc, total_cost, created_at, updated_at`
- **Beat**：`id, project_id, index(1..5，唯一约束), name, synopsis, mood(枚举), grid_size(3|2), duration_s, bridge_note(衔接), memo(备注), status(未填|已填|生成中|已生成|失败), current_segment_id`
- **GridCell**：`id, beat_id, index(1..3), description, is_active(切2时第3格为false)`
- **PromptSnapshot**：`id, job_id, full_prompt_text, params_json, assembled_at`（不可变）
- **GenerationJob**：`id, beat_id, state(排队中|生成中|成功|失败), retry_count, error_category, cost_estimate, provider_task_id, created_at, finished_at`
- **Segment**：`id, job_id, beat_id, video_url, thumb_url, duration_s, created_at`

### 9.3 数据规则

- Beat 行数由 Project 创建事务固定写入 5 行，无独立创建/删除 API（对应 R3）；
- `bridge_note`、`memo`、`name` 字段在 Prompt 组装器中位于硬排除清单（对应 R2）；
- PromptSnapshot 一经写入不可更新（审计与复现依据，对应 AC-6.9）。

## 11. 页面原型（V1.0 共 4 页）

### 11.1 项目列表页

```
┌──────────────────────────────────────────────┐
│  Logo   我的项目                  [＋ 新建项目] │
├──────────────────────────────────────────────┤
│ ┌────────────┐ ┌────────────┐ ┌────────────┐ │
│ │ 项目卡      │ │ 项目卡      │ │ 项目卡      │ │
│ │ 名称/题材   │ │            │ │            │ │
│ │ 9:16 · 60s │ │            │ │            │ │
│ │ ●●●○○ 进度 │ │            │ │            │ │
│ │ [打开][⋯]  │ │            │ │            │ │
│ └────────────┘ └────────────┘ └────────────┘ │
└──────────────────────────────────────────────┘
```

- 新建项目弹窗含 5.1.1 全部强制字段；创建成功直接进入编辑页（11.2）。
- 项目卡"⋯"菜单：重命名 / 删除（二次确认）。
- 进度点阵 = 五节拍状态（对应左导航状态点语义）。

### 11.2 节拍编辑页（核心页）

```
┌──────────────────────────────────────────────────────────────┐
│ ← 项目名          [生成全集]  [队列] [成片页]                    │
├──────────┬──────────────────────────────┬────────────────────┤
│ 左导航(5) │  节拍卡编辑区                  │  Prompt 实时面板     │
│──────────│  节拍名称 [钩子________]       │ ┌────────────────┐ │
│ ● 1 钩子  │  剧情概要 [____________]      │ │[项目级]风格词…   │ │
│ ○ 2 冲突  │  情绪基调 (紧张|温情|…)        │ │[项目级]主角…     │ │
│ ○ 3 升级  │  画面宫格  [3宫格|2宫格]       │ │[节拍]情绪+概要…  │ │
│ ○ 4 反转  │  ┌─────┐┌─────┐┌─────┐       │ │[宫格]画面1→2→3  │ │
│ ○ 5 悬念  │  │画面1 ││画面2 ││画面3 │      │ └────────────────┘ │
│          │  └─────┘└─────┘└─────┘        │  [复制Prompt]       │
│          │  时长 [12]s                    │                    │
│          │  衔接(不进AI) [________]       │  [生成本节拍]        │
│          │  备注 [________]               │                    │
├──────────┴───────────────────────────────┴────────────────────┤
│ 项目级(只读)：画风风格词 · 主角形象 · 9:16        自动保存于 2s 前  │
└────────────────────────────────────────────────────────────────┘
```

- 左导航固定 5 项，含状态点（未填/已填/生成中/已生成/失败），点击切换节拍；
- 衔接输入框旁固定灰字标识 **"仅供人读，不进入 AI"**；
- 宫格切换为分段控件，仅 3/2 两档；切 2 时第 3 格折叠为"草稿保留"胶囊；
- **本页及全站无任何"分镜"入口**（R1）；
- "生成本节拍"就绪校验失败时置灰并列出缺失字段。

### 11.3 生成队列页

```
┌──────────────────────────────────────────────┐
│ ← 项目名   生成队列        并发:2  累计费用:¥xx │
├──────────────────────────────────────────────┤
│ 节拍1 钩子   ▶ 生成中   进度… 第2次尝试  [取消] │
│ 节拍2 冲突   ⏳ 排队中                  [取消] │
│ 节拍3 升级   ✅ 成功    12s  ¥x.x  [查看快照]  │
│ 节拍4 反转   ❌ 失败(内容拒绝) [查看原因][重投]  │
│ 节拍5 悬念   — 未提交                          │
└──────────────────────────────────────────────┘
```

- 行内展示状态、重试次数、费用；失败行给出错误归类与建议动作；
- "查看快照"打开该任务的 PromptSnapshot 只读视图（AC-6.9）。

### 11.4 成片页

```
┌──────────────────────────────────────────────────────┐
│ ← 项目名   成片      [顺序连播] [全部下载] [一键拼接🔒V1.1]│
├──────────────────────────────────────────────────────┤
│ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐│
│ │1 钩子   │ │2 冲突  │ │3 升级   │ │4 反转  │ │5 悬念   ││
│ │▶ 视频   │ │▶ 视频  │ │▶ 视频   │ │(生成中)│ │(未生成) ││
│ │12s     │ │11s     │ │13s     │ │        │ │[去编辑] ││
│ │[下载][↻]│ │[下载][↻]│ │[下载][↻]│ │        │ │        ││
│ └────────┘ └────────┘ └────────┘ └────────┘ └────────┘│
└──────────────────────────────────────────────────────┘
```

- **固定 5 张段卡**，顺序 = 节拍序；未生成显示占位与"去编辑"；
- `↻` = 重新生成（当前字段重投）；下载命名 `项目名_节拍序号_节拍名.mp4`；
- "一键拼接"按钮 V1.0 置灰锁定，标注 V1.1 开放（5.5.5）。

## 12. 交互

- **12.1 导航切换**：编辑页左导航切换节拍时先触发自动保存，保存失败则阻断切换并提示；支持键盘 `↑/↓` 切换节拍。
- **12.2 宫格切换**：3→2 弹出轻提示"第 3 格已保留为草稿，不参与生成"；2→3 静默恢复草稿内容。
- **12.3 Prompt 面板**：字段获焦时，面板中对应片段高亮联动；片段来源标签（项目级/节拍/宫格）不可关闭；复制成功给出 toast。
- **12.4 提交生成**：点击"生成本节拍"后按钮进入 loading，任务入队成功后左导航状态点变"生成中"；重复点击被防抖拦截；"生成全集"弹出确认框列出将提交/将跳过的节拍清单。
- **12.5 失败处理**：失败节拍在左导航显示红点；进入节拍卡顶部显示错误条（归类 + 建议 + [重投] 按钮）。
- **12.6 重生成与回滚**：成片页 `↻` 二次确认"新结果将替换当前段（历史可回滚）"；节拍历史记录列表中任一 Segment 可"设为当前段"。
- **12.7 空态与引导**：新项目首次进入编辑页时，节拍一卡片展示一次性引导（字段说明 + 衔接不进 AI 的规则说明）；成片页全空态引导回编辑页。
- **12.8 删除保护**：删除项目须输入项目名确认；删除后队列中该项目任务一并取消。
- **12.9 断网与冲突**：断网时编辑内容本地暂存并顶部黄条提示；恢复后自动同步。（V1.0 单人使用，无多端并发合并，V1.2 协作时另行设计。）

## 13. 风险

| # | 风险 | 影响 | 缓解 |
|---|---|---|---|
| 1 | Seedance2.5 多镜头能力对"宫格 3 格"支撑不稳（切换生硬/主体漂移） | 核心生成质量 | 前置 API spike 固定多镜头提示语法；提供 2 宫格降级；重生成低成本 |
| 2 | 固定五节拍被部分用户视为束缚 | 转化率 | 定位即约束换产能；V1.1 题材模板提供结构变体 |
| 3 | 内容审核拒绝率高（短剧题材敏感） | 产能 | 错误归类明确"内容拒绝"，提示改写概要/画面描述；不做自动改写规避 |
| 4 | 限流与配额导致批量任务堆积 | 交付时效 | 并发可配、指数退避、队列可视化；成本与配额预警 |
| 5 | 用户把衔接内容写进画面描述，架空 R2 价值 | 拼接质量（V1.1） | 引导文案与字段占位提示明确分工；不做强拦截 |
| 6 | 源稿个别要点存在解读分歧（宫格语义、左导航语义） | 返工 | 解读决策已留痕于交接文档，与源稿责任人核对后仅需局部修订 |

## 14. 壁垒

1. **结构即壁垒**：五节拍 × 3/2 宫格的固定工业模板，把短剧叙事经验固化为产品结构，竞品抄界面抄不走"约束设计"背后的产能数据验证；
2. **Seedance2.5 深度耦合**：多镜头提示语法、参数调优、错误归类均针对单一模型打磨，通用多模型工具在同等成本下达不到同等成片率；
3. **Prompt 组装器资产**：组装顺序、硬排除清单、来源标注机制随版本沉淀为可回归测试的工程资产；
4. **数据飞轮（V1.1+）**：题材模板由真实项目的高成片率节拍数据反哺，形成"用得越多、模板越准"的正循环；
5. **纪律性红线**：禁止分镜入口、衔接不进 AI 等反直觉约束是经过验证的生产纪律，构成认知壁垒——后来者往往因"加回自由度"而丧失工业化收益。
