## E1 — 五节拍模板库（Template Library）

### `US-1-01` 新建即得锁定结构

> **作为** `U-WRITER`，**我希望**新建项目后直接拿到 5 块节拍板，**以便**不用自己搭结构就能开始写内容。

- 优先级：`P0` ｜ 对应：`FR-1-01`、`FR-1-02`、`RULE-2`

**AC：**
1. Given 在项目列表页，When 输入项目名并确认新建，Then 系统创建 `beat_list` 长度恒为 5 的项目并跳转核心编辑器。
2. Given 新建完成，Then 5 块板的 `beat_name` 依次为 开篇钩子 / 矛盾建立 / 打压升级 / 反转蓄力 / 断集留客，`group_id` 依次为 `G1`–`G5`，均为只读。
3. Given 新建完成，Then B1–B4 各渲染 3 个宫格、B5 渲染 2 个宫格。
4. Given 新建完成，Then `time_range`、`duration`、`transition_rule` 按 `PRD-001 §5.1` 基准预置，`total_duration` = 88s。
5. Given 新建完成，Then `frame_list` 各帧 `content` 为空，`prompt_final` 与 `video_url` 为空。

### `US-1-02` 帧语义占位提示

> **作为** `U-WRITER`，**我希望**每个宫格告诉我这一格该写什么，**以便**照着结构填不跑偏。

- 优先级：`P0` ｜ 对应：`FR-1-05`、`FR-1-06`

**AC：**
1. Given 打开 B1，Then 三格占位提示依次为 冲击 / 反应 / 环境。
2. Given 打开 B2–B4，Then 三格提示为"三帧递进"的第 1/2/3 帧语义。
3. Given 打开 B5，Then 两格提示为 抛出悬念 / 最高势能处切断。
4. Given 占位示例文案存在，When 未输入任何内容，Then 示例文案不写入数据、不参与 prompt 组装、不计入完成度。

### `US-1-03` 结构不可增删

> **作为** `U-DIRECTOR`，**我希望**系统根本不给"加板/删板"的入口，**以便**结构永远合规。

- 优先级：`P0` ｜ 对应：`FR-1-04`、R5

**AC：**
1. Given 在核心编辑器，Then 页面不存在"添加节拍板""删除节拍板""调整板顺序"任何控件。
2. Given 直接调用接口尝试提交 4 板或 6 板，Then 数据层拒绝并返回明确错误。
3. Given 直接调用接口尝试修改 `beat_name` 或 `group_id`，Then 数据层拒绝。

### `US-1-04` 宫格数不可改

> **作为** `U-DIRECTOR`，**我希望**宫格数由板序决定，**以便**不出现结构漂移。

- 优先级：`P0` ｜ 对应：`FR-1-03`、R7

**AC：**
1. Given 任一板，Then 不存在"增加宫格""减少宫格"控件。
2. Given 直接调用接口给 B5 提交 3 个 `frame`，Then 数据层拒绝（B5 恒为 2）。
3. Given 直接调用接口给 B1–B4 任一板提交 2 或 4 个 `frame`，Then 数据层拒绝。

## E2 — 可视化节拍编辑器（Visual Beat Editor）

### `US-2-01` 一屏看清五板结构

> **作为** `U-WRITER`，**我希望**在主编辑区看到 B1→B5 的完整结构，**以便**判断整集节奏是否成立。

- 优先级：`P0` ｜ 对应：`FR-2-01`、`FR-2-09`

**AC：**
1. Given 打开核心编辑器，Then 5 块板按 B1→B5 纵向排列，顺序不可改。
2. Given 任一板板头，Then 显示 `Bn`、节拍名、`Gn`、时间位、时长。
3. Given 顶部栏，Then 显示整集总时长；70–90s 内为正常态，越界为警示态并说明原因。

### `US-2-02` 按左→右填节拍帧

> **作为** `U-WRITER`，**我希望**从左到右把关键画面信息点写进宫格，**以便**表达这一段的画面走向。

- 优先级：`P0` ｜ 对应：`FR-2-03`、`FR-2-04`、R4

**AC：**
1. Given 任一宫格，When 输入文本并失焦，Then 内容持久化到对应 `frame.content`。
2. Given 编辑器内任意位置，Then 不存在拖拽重排、上移/下移、排序或"设为主帧"控件。
3. Given 提交生成，Then 帧内容按 `index` 升序（左→右）参与后续处理。
4. Given 直接调用接口提交乱序 `index`，Then 数据层拒绝。

### `US-2-03` 填板级情绪与剧情核心

> **作为** `U-WRITER`，**我希望**为每块板写清情绪与一句话剧情，**以便**AI 知道这一段要什么。

- 优先级：`P0` ｜ 对应：`FR-2-05`、`FR-2-07`

**AC：**
1. Given 任一板，Then 提供"本段情绪"与"剧情核心"两个必填输入。
2. Given 任一项为空，Then 该板生成动作不可用，并提示缺失项名称。
3. Given 输入超出 `PRD-001 §8` 字数上限，Then 即时提示并阻断保存。

### `US-2-04` 只写镜头节奏，不写刀数

> **作为** `U-DIRECTOR`，**我希望**只描述节奏感，**以便**把组内切分留给 AI。

- 优先级：`P0` ｜ 对应：`FR-2-06`、`RULE-6`、R1

**AC：**
1. Given 任一板，Then 提供"镜头节奏"输入，占位文案示意"快切递进 / 先慢后紧"这类形容。
2. Given 编辑器内，Then 不存在剪辑刀数、单个画面时长、组内转场等任何输入项。
3. Given 在镜头节奏中写入逐画面时长式内容，Then 提示该字段只接受节奏形容（提示级，不阻断）。

### `US-2-05` 板时长受 30s 硬约束

> **作为** `U-DIRECTOR`，**我希望**超过 30s 时立刻被拦住，**以便**不浪费一次生成。

- 优先级：`P0` ｜ 对应：`FR-2-08`、R3

**AC：**
1. Given 任一板，When 调整时长至 ≤30s，Then 保存成功并重算 `total_duration`。
2. Given 任一板，When 调整时长至 >30s，Then 即时报错、阻断保存、生成动作不可用。
3. Given 直接调用接口提交 `duration = 31`，Then 后端拒绝（不依赖前端拦截）。

### `US-2-06` 板级完成度一眼可见

> **作为** `U-WRITER`，**我希望**知道哪块板还没填完，**以便**不漏内容就去生成。

- 优先级：`P0` ｜ 对应：`FR-2-10`

**AC：**
1. Given 板的情绪 / 镜头节奏 / 剧情核心 / 全部帧内容齐备且时长合规，Then 板显示"可生成"。
2. Given 任一必填缺失，Then 板显示"待补全"并列出缺失项。
3. Given 板处于"待补全"，When 点击生成，Then 动作不可用且给出原因。

### `US-2-07` 自动保存与保存态可见

> **作为** `U-WRITER`，**我希望**内容自动保存，**以便**不怕丢稿。

- 优先级：`P0` ｜ 对应：`FR-2-11`、`NFR-8`

**AC：**
1. Given 任一字段，When 失焦，Then 触发保存，顶部栏显示"已保存"及时间。
2. Given 保存失败，Then 显示失败态与重试入口，内容保留在输入框中不丢失。

## E3 — Prompt 组装器（Prompt Assembler）

### `US-3-01` 按固定公式自动组装

> **作为** `U-WRITER`，**我希望**prompt 自动按标准公式拼好，**以便**每板质量稳定。

- 优先级：`P0` ｜ 对应：`FR-3-01`、`RULE-8`

**AC：**
1. Given 板槽位齐备，Then 组装结果严格为 `固定前缀 + 本段情绪 + 时长 + 镜头节奏 + 剧情核心` 的顺序。
2. Given 任意槽位内容变化，Then 组装结果按同一顺序重算，顺序永不改变。
3. Given 以 `METH-003 §3–§7` 五板【示例】槽位作为输入，Then 组装结果与该文档的组装结果一致（黄金回归用例）。

### `US-3-02` 固定前缀只读

> **作为** `U-DIRECTOR`，**我希望**画风与人物一致性前缀无法被改，**以便**全集画风统一、五官不漂移。

- 优先级：`P0` ｜ 对应：`FR-3-02`

**AC：**
1. Given prompt 面板，Then 固定前缀以只读形式展示，无编辑与删除入口。
2. Given 直接调用接口尝试覆盖前缀，Then 服务端忽略入参并使用系统常量。
3. Given 前缀常量缺失，Then 组装失败并报"固定前缀不可为空"。

### `US-3-03` 转场绝不进 prompt

> **作为** `U-DIRECTOR`，**我希望**衔接手法永远不出现在 prompt 里，**以便**AI 不去做组间的事。

- 优先级：`P0` ｜ 对应：`FR-3-04`、`RULE-9`、R8

**AC：**
1. Given 板已设置 `transition_rule`，When 组装 prompt，Then 组装输入白名单只含 `emotion`、`duration`、`ai_param.camera_rhythm`、`ai_param.plot_core`，衔接字段不被读取。
2. Given 组装结果，When 扫描 `FR-3-03` 转场词清单，Then 命中数为 0；命中即拦截生成并指出命中词。
3. Given 用户在情绪/节奏/剧情核心中手写了转场词，Then 组装后扫描命中，阻断生成并提示改写。

### `US-3-04` 实时预览且足够快

> **作为** `U-WRITER`，**我希望**改完立刻看到 prompt，**以便**边写边判断。

- 优先级：`P0` ｜ 对应：`FR-3-06`、`NFR-2`

**AC：**
1. Given 修改任一槽位，Then prompt 预览在 **≤200ms**（P95）内更新。
2. Given 槽位不齐，Then 预览显示已组装部分并标出缺失槽位，不报未知错误。

### `US-3-05` 结果只读可复制

> **作为** `U-OPS`，**我希望**能复制最终 prompt，**以便**归档与排查。

- 优先级：`P0` ｜ 对应：`FR-3-05`

**AC：**
1. Given prompt 面板，Then 提供复制动作，复制内容与提交内容完全一致。
2. Given prompt 面板，Then 不存在自由编辑 prompt 的输入框。
3. Given 生成成功，Then `prompt_final` 作为快照留存，后续修改槽位不改写历史快照。

## E4 — 生成引擎（Generate Engine）

### `US-4-01` 一板一次生成

> **作为** `U-WRITER`，**我希望**点一块板就生成这一段，**以便**生产单元与叙事单元一致。

- 优先级：`P0` ｜ 对应：`FR-4-01`、`FR-4-02`、`RULE-1`、`RULE-10`

**AC：**
1. Given 板可生成，When 点击"生成本板"，Then 系统发起**恰好 1 次** Seedance 2.5 调用。
2. Given 界面，Then 不存在"拆分本板生成""合并多板生成"入口。
3. Given 生成记录，Then `generate_task.beat_id` 与板 1:1 绑定。

### `US-4-02` 生成前置校验拦截

> **作为** `U-DIRECTOR`，**我希望**不合规的板压根提交不出去，**以便**不浪费额度。

- 优先级：`P0` ｜ 对应：`FR-4-03`

**AC：**
1. Given 板时长 >30s，When 触发生成，Then 阻断并提示"单板时长不得超过 30 秒"。
2. Given 帧数与板序不匹配，When 触发生成，Then 阻断并提示宫格数要求。
3. Given prompt 命中转场词，When 触发生成，Then 阻断并指出命中词。
4. Given 必填槽位缺失，When 触发生成，Then 阻断并列出缺失项。

### `US-4-03` 生成状态可见

> **作为** `U-WRITER`，**我希望**看到每块板的生成进度，**以便**知道等多久。

- 优先级：`P0` ｜ 对应：`FR-4-04`、`FR-4-05`

**AC：**
1. Given 提交生成，Then 板状态依次为 排队 → 生成中 → 成功/失败。
2. Given 生成成功，Then 写入 `video_url` 与 `prompt_final` 快照，板内可预览。
3. Given 生成失败，Then 显示可读失败原因与重试入口。

### `US-4-04` 单板返工不牵连其他板

> **作为** `U-WRITER`，**我希望**只重做不满意的那一板，**以便**其他板不受影响。

- 优先级：`P0` ｜ 对应：`FR-4-06`、`SC3`

**AC：**
1. Given 第 3 板已生成，When 修改第 3 板并重新生成，Then 仅第 3 板状态与 `video_url` 变化。
2. Given 重生成进行中，Then 其余 4 板仍可正常编辑与预览。

### `US-4-05` 失败重试且幂等

> **作为** `U-OPS`，**我希望**重复点击不会产生重复任务，**以便**不产生重复消耗。

- 优先级：`P0` ｜ 对应：`FR-4-07`、`NFR-3`

**AC：**
1. Given 同一板同一入参，When 连续提交两次，Then 只生成一个任务（幂等键命中）。
2. Given 修改了任一 prompt 槽位后再提交，Then 视为新任务（幂等键变化）。
3. Given 任务失败，When 点击重试，Then 复用同一板并可再次执行。

### `US-4-06` 整集一键生成

> **作为** `U-OPS`，**我希望**一次触发把 5 板都排上，**以便**减少点击。

- 优先级：`P0` ｜ 对应：`FR-4-08`

**AC：**
1. Given 5 板均可生成，When 点击"生成整集"，Then 按 B1→B5 顺序触发 **5 次独立**调用（不合并为一次）。
2. Given 其中某板不合规，Then 该板被跳过并给出原因，其余板照常执行。

## E5 — 组间衔接管理器（Inter-group Transition Manager）

### `US-5-01` 在上一块板上设置衔接

> **作为** `U-DIRECTOR`，**我希望**在每块板尾部设定"怎么进入下一板"，**以便**掌控组间节奏。

- 优先级：`P0` ｜ 对应：`FR-5-01`、`FR-5-02`、`RULE-6`

**AC：**
1. Given 板尾衔接位，Then 显示"本板结束 → 进入下一板"的语义标题。
2. Given 打开衔接选择，Then 可选项恰为 5 项封闭枚举（`PRD-001 §6.5`），无自定义输入。
3. Given 选择完成，Then 写入本板 `transition_rule.codes`，不写入下一板。
4. Given 系统侧，Then 不存在自动推荐/自动决定衔接的行为。

### `US-5-02` 支持主手法 + 修饰叠加

> **作为** `U-DIRECTOR`，**我希望**能像基准 B4 那样叠加"卡点硬切 + BGM 升调"，**以便**还原样板效果。

- 优先级：`P0` ｜ 对应：`FR-5-03`

**AC：**
1. Given 衔接选择，Then 最多可选 2 项，超出即禁用其余选项。
2. Given 新建项目的 B4，Then 默认 `codes = [BEAT_SYNC_CUT, BGM_PITCH_CUT]`。

### `US-5-03` B5 衔接锁定

> **作为** `U-DIRECTOR`，**我希望**B5 固定为黑屏截断，**以便**断集留客形态不被破坏。

- 优先级：`P0` ｜ 对应：`FR-5-04`

**AC：**
1. Given B5 衔接位，Then 显示"无转场 / 黑屏截断"且为只读（`locked = true`）。
2. Given 直接调用接口修改 B5 的 `transition_rule`，Then 数据层拒绝。

### `US-5-04` 衔接只影响后期，不影响生成

> **作为** `U-DIRECTOR`，**我希望**改衔接不会导致重新生成，**以便**分清人机边界。

- 优先级：`P0` ｜ 对应：`FR-5-05`、`RULE-9`

**AC：**
1. Given 板已生成成功，When 修改 `transition_rule`，Then `prompt_final` 与 `video_url` 均不变，板不进入待重生成态。
2. Given 生成请求体，Then 不含任何衔接字段（`stage = POST_COMPOSITE` 仅用于后期）。
3. Given 编辑器，Then 宫格与宫格之间不存在任何转场控件。

### `US-5-05` 衔接总表可导出

> **作为** `U-OPS`，**我希望**拿到 `B1→B2 … B5→下一集` 的衔接表，**以便**交给后期。

- 优先级：`P0` ｜ 对应：`FR-5-06`

**AC：**
1. Given 项目，When 导出衔接表，Then 输出 5 行：B1→B2、B2→B3、B3→B4、B4→B5、B5→下一集。
2. Given 导出内容，Then 每行含衔接枚举名与生效阶段（后期合成）。
3. Given B3 存在 `pending_canon` 标记（`PRD-001 §12 O-P2-1`），Then 导出中显式标注"待法源确认"。

## E6 — 成片管理（Final Cut Management）

### `US-6-01` 按项目查看成片进度

> **作为** `U-OPS`，**我希望**在成片页看到每个项目的完成度，**以便**排交付。

- 优先级：`P0` ｜ 对应：`FR-6-01`、`FR-6-06`

**AC：**
1. Given 成片页，Then 列出项目名、总时长、生成完成度（n/5）、更新时间。
2. Given 未齐 5 段，Then 明确列出缺失板号，且不可标记为可交付。

### `US-6-02` 分板预览与下载

> **作为** `U-OPS`，**我希望**逐板预览和下载视频，**以便**核对与交付。

- 优先级：`P0` ｜ 对应：`FR-6-02`

**AC：**
1. Given 项目已有生成结果，Then 列出 B1–B5 的视频条目，可预览、可下载。
2. Given 某板未生成，Then 该条目显示空态与"回到编辑器"入口。

### `US-6-03` 成片登记

> **作为** `U-OPS`，**我希望**登记后期合成完成的成片，**以便**形成交付记录。

- 优先级：`P0` ｜ 对应：`FR-6-04`

**AC：**
1. Given 成片页，Then 可填入成片链接与备注并保存。
2. Given 已登记，Then 记录展示登记时间与操作人。

### `US-6-04` 一键导出飞书

> **作为** `U-OPS`，**我希望**把项目信息一键导出到飞书，**以便**团队协同。

- 优先级：`P0` ｜ 对应：`FR-6-05`、`NFR-5`

**AC：**
1. Given 项目，When 点击导出飞书，Then 导出成功并返回可访问链接。
2. Given 导出内容，Then 含项目名、总时长、5 板规格（节拍名/G/时间位/时长/宫格数）、各板 `prompt_final`、衔接总表。
3. Given 导出失败，Then 给出可读失败原因与重试入口。

### `US-6-05` 生成版本历史

> **作为** `U-OPS`，**我希望**保留同一板的多次生成结果，**以便**挑最好的一版。

- 优先级：`P1` ｜ 对应：`FR-6-07`

**AC：**
1. Given 同板多次生成成功，Then 保留历史版本并可切换选用。
2. Given 选用某版本，Then 该版本作为该板当前 `video_url`。

## E7 — 项目生命周期（Project Lifecycle）

### `US-7-01` 项目列表与检索

> **作为** `U-OPS`，**我希望**在项目列表快速找到项目，**以便**继续编辑。

- 优先级：`P0`

**AC：**
1. Given 项目列表，Then 显示项目名、总时长、完成度、更新时间，并按更新时间倒序。
2. Given 输入关键词，Then 按项目名过滤。
3. Given 点击项目，Then 进入核心编辑器且定位到该项目上下文。

### `US-7-02` 新建项目

> **作为** `U-WRITER`，**我希望**用最少步骤开新集，**以便**立刻开始写。

- 优先级：`P0` ｜ 对应：§7.1

**AC：**
1. Given 项目列表，When 新建并输入项目名，Then 创建成功并进入编辑器。
2. Given 项目名为空或超长，Then 阻断并提示。
3. Given 创建成功，Then 满足 `US-1-01` 全部 AC。

### `US-7-03` 复用项目

> **作为** `U-OPS`，**我希望**复刻上一集的结构与参数但清空内容，**以便**同结构换题材。

- 优先级：`P0` ｜ 对应：§7.2、`SC2`、`G5`

**AC：**
1. Given 任一项目，When 执行复用，Then 新项目继承 `beat_list` 结构、节拍语义、宫格数、`time_range`、时长、`ai_param` 参数、`transition_rule`。
2. Given 复用完成，Then 全部 `frame.content` 为空、`prompt_final` 为空、`video_url` 为空、生成状态归零。
3. Given 复用完成，Then 新项目仍为 5 板锁定结构，`total_duration` 等于被复用项目的总时长。
4. Given 复用完成，Then 原项目不发生任何变化。

### `US-7-04` 空态引导

> **作为** 新用户，**我希望**在没有项目时知道下一步做什么，**以便**顺利开始。

- 优先级：`P0`

**AC：**
1. Given 项目列表为空，Then 显示空态说明与"新建项目"主动作。
2. Given 成片页无数据，Then 显示空态说明与"去编辑器"入口。
