## 2. 固定前缀与组装公式【CANON】

```

```

组装公式：

```
固定前缀 + 本段情绪 + 时长 + 镜头节奏 + 剧情核心
```

**转场绝不进入 prompt**（Transitions NEVER in AI prompt）。下文每板的"组间衔接"字段仅供后期合成使用，

## 9. 模板库落地要求（给 P0 实现）

1. 模板库需内置本文的 5 板骨架：`beat_type`、`g_index`、`time_start/time_end`、`duration`、`frame_count`、`transition_out`。
2. `frame_count` 由板序决定：B1–B4 = 3，B5 = 2，**不可由用户修改**。
3. `transition_out` 取值必须落在 5 种封闭枚举内（见 [`glossary.md`](./glossary.md) §5）。
4. Prompt 组装器读取 `emotion / duration / camera_rhythm / plot_core` 四槽位，前置固定前缀，**过滤任何转场字段**。
5. 校验器至少覆盖：`len(beat_list) == 5`、`duration <= 30`、`frame_count` 与板序匹配、prompt 不含转场词。
